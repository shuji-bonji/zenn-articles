title: "仕様パッケージを手元に置く"
---

DM を確かめるには、S1000D の XML スキーマと既定 BREX が要ります。どちらも、S1000D のダウンロードサイトで配布されている仕様パッケージに入っています。この章では、パッケージの中身と、どのフォルダーを使うかを説明します。入手の手順そのものは、入門の「[入手方法と学習の進め方](https://zenn.dev/shuji_bonji/books/s1000d-intro/viewer/how-to-learn)」に書いています。

## スキーマと既定 BREX を各自で入手する理由

DM を XSD と BREX で確かめるには、何を使うかによらず、検証を行うコンピューターに XSD と既定 BREX のファイルを置いておく必要があります。XML エディターでスキーマ検証をするときも、自分で書いたスクリプトで検証するときも、この本で使う S1000D Stack で検証するときも、同じファイルを読み込みます。

これらのファイルは自由に配れないため、この本にも S1000D Stack にも入れていません。読者が各自でダウンロードサイトから入手します。商用の CSDB 製品を使っている場合は、製品がスキーマを持っていることがあるので、製品の説明書で確かめてください。

配れない理由は利用条件にあります。Issue 7 の仕様書の冒頭にある利用条件を著者は次のように読みました。法的な判断ではなく、私的な要約です。

| 内容 | 著者の読み |
| --- | --- |
| 利用の許諾 | 条件を守る限り、利用することは認められている。再配布の権利は与えられていない |
| 対象 | 仕様書だけでなく、XML スキーマ、例（XML とスタイルシート）、ダウンロードページのほかの情報も含む |
| 改変 | 翻訳と翻案は認められていない。ビジネスルールを足すことは認められている |
| 再配布が認められる相手 | 維持団体の会員企業や、加盟国の国防省などに限られる。個人の開発者は含まれない |

このため、S1000D Stack は、スキーマに似せた別のスキーマを作って配る方法も取っていません。検証には利用者が入手した本物のスキーマを使います。

## パッケージの中身

Issue 7 の配布物は 1 つの zip です。展開すると、仕様書の PDF が 1 つと、内側の zip が 10 本出てきます。内側の zip も展開します。

| 内側の zip | 中身 | この本で使うか |
| --- | --- | --- |
| XML Schema Package | XSD（`xml_schema_flat/` に 33 本。DM の種類ごとのスキーマと、それらが読み込む共通のスキーマ）、使える図の形式の一覧 | 使う（8 章） |
| Default BREX | 既定 BREX の DM が 1 件 | 使う（9 章） |
| Bike Samples | 自転車を題材にした公式サンプルの CSDB | 件数を数えるときだけ |
| Data Dictionary | 要素と属性の定義 | 調べるときに使う |
| Business Rules Template | ビジネスルール文書のひな形 | 使わない |
| Business Rules Decision Point Index | ビジネスルールの決定点の一覧（表計算のファイル） | 使わない |
| Example SNS | システムの番号の体系の例 | 使わない |
| Front Matter Samples | 表紙や目次などの例 | 使わない |
| Functionality Matrix | 機能マトリックス | 使わない |
| Unit of Measure | 単位の定義 | 使わない |

仕様書の PDF は 3,700 ページあります。章の番号で探せるように、自分のコンピューターで文章を検索できる状態にしておくと便利です。

## `xml_schema_flat` は 2 つあります

展開したフォルダーの中に `xml_schema_flat/` という名前のフォルダーが 2 つ見つかります。使えるのは片方だけです。

| 場所 | 内容 | 使えるか |
| --- | --- | --- |
| XML Schema Package の中 | 配布物の本体。ほかのスキーマを読み込む指定（`xs:import`）が、同じフォルダーのファイル名で書かれている | 使える |
| Data Dictionary の中 | データ辞書の表示用の写し。33 本すべてが、本体と内容が違う。`xs:import` が、インターネット上の URL で書かれている | 使えない |

データ辞書の側を使うと、検証の道具がインターネットからスキーマを取りに行こうとして、失敗します。検証には、XML Schema Package の側を指定してください。

## 既定 BREX のファイル

既定 BREX は、`DMC-S1000D-J-04-10-0301-00A-022A-D_001-00_EN-US.XML` というファイルです。名前の読み方は次の章で説明します。

このファイルには、S1000D の Issue を表す 1 文字（システム差異コード）に、資料による食い違いがあります。

| 資料 | 既定 BREX のシステム差異コード |
| --- | --- |
| 仕様書の本文（Chap 4.10.3） | `I` |
| 同梱されている既定 BREX のファイル | `J` |
| データ辞書の中の見本 | `X` |

実際に DM から参照するのは同梱されているファイルです。自分の BREX から既定 BREX を参照するときは、ファイルの中の値（`J`）に合わせます。

## 置き場所を S1000D Stack に伝える

S1000D Stack の MCP サーバーには、パッケージを展開したフォルダーの場所を次のどちらかで伝えます。

| 方法 | 書くもの |
| --- | --- |
| 環境変数 | `S1000D_SPEC_DIR` に、展開したフォルダーの場所 |
| 設定ファイル | `~/.config/s1000d-stack/config.json` の `specDir` |

設定ファイルの例です。`csdbDirs` は、DM を置いたフォルダー（CSDB）の場所です。

```json
{
  "specDir": "/Users/you/specs/s1000d/issue-7",
  "csdbDirs": ["/Users/you/work/kenbaiki/csdb"]
}
```

環境変数と設定ファイルの両方があるときは環境変数が使われます。フォルダーの名前は自由です。サーバーは、指定したフォルダーの下から、既定 BREX とスキーマのフォルダーを探します。

## 確かめ方

置き場所が正しく伝わったかは、s1000d-verify-mcp の [`list_schemas`](https://shuji-bonji.github.io/s1000d-stack/ja/reference/stack/verify/list-schemas/) で確かめられます。見つかったスキーマのフォルダー、その版、使えるスキーマの名前が返ります。

DM を 1 件検証して、確かめることもできます。検証の結果には使ったスキーマのファイルの場所が入ります。次の値は券売機の手順の DM を検証したときのものです。場所が XML Schema Package の中になっていれば、正しい側を使えています。

```text
…/xml-schema-package/S1000D Issue 7 XML Schema Package/xml_schema_flat/proced.xsd
```

## 実装するときの注意

### フォルダーの名前を決め打ちにしない

内側の zip を展開したフォルダーの名前は、利用者によって違います。s1000d-core は、名前を決めずに、中身で探します。

| 探すもの | 見分け方 |
| --- | --- |
| スキーマのフォルダー | `brex.xsd` があるフォルダー。ただし、データ辞書のフォルダーの下は除く |
| 既定 BREX | ファイル名が `DMC-S1000D-…-022A-D` の形で、中身の DMC がファイル名と一致し、自分自身を参照しているもの |

既定 BREX をファイル名だけで探してはいけません。データ辞書の見本には、ファイル名の DMC と中身の DMC が違うものがあります。これを既定 BREX として使うと、BREX の参照をたどる処理が、同じ 2 つのファイルの間を行き来して終わりません。対策を入れる前は DM 1 件の検査に 137 秒かかりました。訪れた参照を記録し、中身の DMC が一致するファイルを優先するようにした後は、117 件の DM を 10 秒で検査できました。

### 環境変数が届かない起動の仕方がある

デスクトップアプリからプラグインとして起動した MCP サーバーには、利用者が設定した環境変数が届かないことがあります。著者の環境では、`S1000D_SPEC_DIR` が届きませんでした。設定ファイルから読む方法を足したのはこのためです。ホームフォルダーの場所さえ分かれば、設定ファイルは読めます。

## この章のポイント

- スキーマと既定 BREX は、利用条件のために自由に配れません。この本と S1000D Stack には入っていないので、各自で入手します。
- `xml_schema_flat/` は 2 つあります。使えるのは XML Schema Package の中のものです。
- 既定 BREX のシステム差異コードは、仕様書の本文と同梱のファイルで違います。参照するときはファイルの値に合わせます。
