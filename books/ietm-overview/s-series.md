---
title: "S シリーズと IPS"
---

S1000D は、装備の製品支援を扱う一連の国際仕様「S シリーズ」の一つで、そのうち技術出版物を担当しています。部品などの物資の管理、後方支援の分析、予防整備、運用中のデータのフィードバック、訓練は、S シリーズのそれぞれ別の仕様が扱います。S シリーズ全体が対象にしている分野を、統合製品支援（Integrated Product Support、IPS）と呼びます。以前の文書では、同じ分野を統合後方支援（Integrated Logistics Support、ILS）と呼んでいました。

米国航空宇宙工業会（Aerospace Industries Association、AIA）は、S シリーズを、製品支援に必要な技術データを途切れなく受け渡すための仕様群と説明しています。

S1000D を採用しただけで、ほかの S シリーズの仕様も採用したことにはなりません。また、ほかの仕様が S1000D のデータモジュールの代わりになるわけでもありません。この章では、S シリーズの構成と、S1000D との関係を説明します。

## 一連の仕様として作られた理由

AIA によると、1993 年に NATO の加盟国が、技術データと製品支援のデータを、共通の形式でデジタルにやり取りするための ILS 仕様を、統一した一式として整える必要があると表明しました。

現在の S シリーズは、S1000D Council と S-Series IPS Council が中心となって、国際的に開発と管理を行っています。Council と Steering Committee には、AIA と欧州航空宇宙防衛工業会（Aerospace, Security and Defence Industries Association of Europe、ASD）の産業界と各国国防省のメンバーが参加しています。ATA e-Business Program が加わるのは S1000D だけです。

AIA は、S シリーズは航空宇宙と防衛のために作られたものの、ほかの分野にも使えると書いており、例として海事、海中、鉄道、建設、農業を挙げています。S1000D の公式サイトも、防衛（陸・海・空）、民間航空、建設、船舶を用途に挙げています。

## S シリーズの仕様の一覧

AIA の S シリーズのページは、無料で入手できる一式として、次の 7 つを挙げています。説明は AIA のページの表現に合わせています。S1000D の公式サイトのリンク集では、SX000i を「ガイド（guide）」、ほかを「仕様（specification）」または「手順仕様（procedure specification）」と呼び分けているため、SX000i には両方の呼び方を載せています。

| 仕様 | 内容 |
| --- | --- |
| SX000i | 統合製品支援（IPS）の国際仕様。S1000D の公式サイトのリンク集では “International guide for the use of the S-Series IPS specifications”（S シリーズを使うための国際ガイド）とも紹介されている |
| S1000D | 共通ソースデータベースを用いる技術出版物のための国際仕様 |
| S2000M | 物資管理（material management）の国際仕様 |
| S3000L | 後方支援分析（Logistics Support Analysis、LSA）の国際手順仕様 |
| S4000P | 予防整備の計画を作り、継続的に改善するための国際仕様 |
| S5000F | 運用中のデータのフィードバックの国際仕様 |
| S6000T | 訓練の分析と設計の国際手順仕様 |

S シリーズのサイトの著作権表示によると、S1000D は ASD、AIA、ATA／A4A の 3 団体が共同で開発し、ほかの仕様は AIA と ASD の 2 団体が共同で開発しています。

この 7 つのほかに、S シリーズのサイトは、複数の仕様にまたがって使う次の文書も公開しています。

| 文書 | 内容 |
| --- | --- |
| SX001G | S シリーズ共通の用語集 |
| SX002D | 複数の仕様に共通するデータ要素をまとめた共通データモデル。仕様をまたいでデータの形をそろえるための文書 |
| SX004G | UML モデルの読み方のガイド。SX002D の読み方も含む |
| SX005G | XML スキーマの実装ガイド。S1000D 以外の仕様が対象 |

このほか、S1000D への入力データの仕様である S1000X（Issue 1.0、2021 年 4 月）もあります。ただし、SX000i のダウンロードページには、2021 年の S シリーズの一式には含まれないと書かれているため、本書では一式には数えていません。また、SX003X のように、本書が参照した公式ページでは確認できなかった文書も、一覧には入れていません。

## S1000D とほかの仕様の関係

S1000D が扱うのは、人が読む技術情報をデータモジュールとして作り、共通ソースデータベースで管理し、出版物にまとめることです。ほかの仕様は、それぞれ別の問題を扱います。

```mermaid
flowchart TB
  IPS["IPS / SX000i：仕様群の使い方"]
  IPS --> T["S1000D：技術出版物"]
  IPS --> M["S2000M：物資管理"]
  IPS --> L["S3000L：後方支援分析"]
  IPS --> P["S4000P：予防整備"]
  IPS --> F["S5000F：運用中のフィードバック"]
  IPS --> R["S6000T：訓練の分析と設計"]
```

:::message
図の矢印は、SX000i が仕様群全体の使い方を扱っていることを示すものです。データが必ずこの向きに流れることを表すものではありません。データのやり取りの詳細は、各仕様で確認してください。
:::

- **S2000M** は、部品などの物資の管理方法を扱います。技術出版物の手順そのものは扱いません。
- **S3000L** は、後方支援の分析の進め方を扱います。S1000D の利点のページは、S1000D のデータを LSAR（後方支援分析の記録）などの元データと連携できると述べていますが、具体的なデータのやり取りの形式は書かれていません。
- **S4000P** は、予防整備の項目の作り方と改善の方法を扱います。S1000D の Schedules という DM の種類と目的が近い部分はありますが、Schedules の DM が S4000P の出力そのものだとは、公式の概要ページは述べていません。
- **S5000F** は、運用が始まったあとのデータを、開発や整備の側に戻す方法を扱います。IETP の画面で技術者が見る手順とは別の流れです。
- **S6000T** は、訓練の分析と設計の方法を扱います。IETM のビューアで手順を表示することとは、作るものが違います。
- **SX000i** は、これらの仕様を IPS として組み合わせて使う方法をまとめた、全体にまたがる文書です。個々の仕様の代わりにはなりません。

## IETM との関係

米国の IETM は、技術者に技術情報を対話的に表示するという考え方から始まりました。S1000D は、その表示の元になるデータを、国際的にやり取りできる単位で作るための仕様です。S シリーズのほかの仕様は、技術情報の周りにある製品支援、つまり部品、分析、予防整備、現場からのデータ、訓練を、それぞれ別のデータとしてやり取りするためのものです。

一つの画面の中で部品を発注したり、整備データを収集したりする機能は、米陸軍の機能マトリックスでは External Processes（外部の業務処理）の行で選べます。

:::message alert
この行の機能を選ぶことと、S2000M や S5000F に準拠することは同じではありません。画面に求める機能と、やり取りするデータの仕様は、契約の中で別々に指定します。
:::

## この章のポイント

- S1000D は、IPS（統合製品支援）のための S シリーズの一つで、技術出版物を担当しています。S シリーズは、1993 年に NATO の加盟国が、ILS 仕様を一式としてデジタルにやり取りする必要を表明したことから始まりました。
- AIA が無料公開の一式として挙げるのは、技術出版物、物資管理、後方支援分析、予防整備、運用中のフィードバック、訓練の 6 つの仕様と、全体の使い方を扱う SX000i です。そのほかに、用語集の SX001G、共通データモデルの SX002D、UML の読み方の SX004G、XML の実装ガイドの SX005G も公開されています。S1000X は、2021 年の一式には含まれていません。
- 画面の機能マトリックスで外部の業務処理を選ぶことと、ほかの S シリーズの仕様に準拠することは、契約上は別の条件です。
